Введите условия — ответ строится только по реальным тестам NASA из датасета. Если подходящих тестов нет, оценка не даётся.

Примеры:

«Те же условия» = ±2 п.п. кислорода и ±10% давления; «рядом» = ±5 п.п. и ±25%. Это правило датасета, а не научный критерий. Данные BRE прочитаны из текста диссертации. Исходы показаны только там, где они есть в таблицах NASA. Это учебный проект NASA Space Apps, а не инструмент пожарной безопасности и не оценка NASA.
